One page per paper, review, or topic. Topic pages consolidate what multiple papers say about one question; paper notes capture a single source.

## Conventions

- **File name**: kebab-case, descriptive — `lecanemab-clarity-ad.mdx`, not `paper-1.mdx`.
- **Frontmatter**: every note sets `title`, `description`, and `search.tags` so it is filterable in search.
- **Sources**: link the DOI or PubMed record at the top of the note. Claims in the note should trace to a source.
- **Timeline**: if the paper marks a milestone (first evidence, approval, major readout), add it to [the timeline](/timeline) too.

## Add a note

Copy the [paper note template](/research/templates/paper-note), save it in `docs/research/`, and fill it in. The sidebar and search index update automatically.
