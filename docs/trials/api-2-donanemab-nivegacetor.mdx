## Why it matters

API-2 tests whether combining an amyloid-clearing antibody (donanemab) with a gamma-secretase modulator (nivegacetor) can effectively alter the disease course in the PSEN1 E280A kindred. It builds upon previous monotherapy failures by targeting the underlying biological cascade specific to this mutation.
