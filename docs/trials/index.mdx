## Add a trial

Copy `templates/trial.mdx` from the repo into `docs/trials/`, fill in the registry data, and run `pnpm publish:docs` to refresh the table above (the research pipeline does this automatically). Milestones (start, readout, approval) also go on [the timeline](/timeline).
