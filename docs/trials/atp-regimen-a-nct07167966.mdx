## Why it matters

Following the failure of AADvac1 to show efficacy in a broad population, this platform trial evaluates the vaccine in a strictly defined biomarker-stratified cohort. It also tests combination therapy with an anti-amyloid agent (donanemab) to see if addressing both pathologies simultaneously yields better outcomes.
