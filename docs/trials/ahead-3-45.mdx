## Why it matters

Tests the core prediction of the [amyloid hypothesis](/research/amyloid-hypothesis): if amyloid removal begins **before symptoms**, does it prevent or delay cognitive decline? Uses plasma [biomarker](/research/biomarkers) pre-screening ahead of confirmatory PET — a model for scalable prevention trials.
